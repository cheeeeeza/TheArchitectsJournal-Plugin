# The Architect’s Journal

A lore-driven Minecraft (Paper) plugin that introduces powerful custom items inspired by ancient prophecy, each with unique abilities, effects, and gameplay mechanics.

## Features
- Custom items with unique abilities (wands, amulets, journals)
- Passive and active effects (levitation, slow falling, resurrection, buffs)
- Cooldown-based abilities to maintain balance
- Custom sounds, particles, and visual feedback
- Event-driven mechanics using the Paper API

## Gameplay
- Special items can be obtained through progression and discovery
- Some abilities activate on right-click, others while held or worn
- Certain effects require items to be held in the main-hand or off-hand
- Abilities are balanced with cooldowns and visual indicators

## Requirements
- Minecraft 1.20+
- Paper / PaperMC server
- Java 17+

## Installation
1. Download the plugin `.jar`
2. Place it into your server’s `plugins/` folder
3. Restart the server
4. Configure the plugin (if applicable)
